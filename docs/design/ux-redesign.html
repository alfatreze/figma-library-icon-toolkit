Icon Library Toolkit: proposed UI

Mockup of the redesign proposed in docs/UX-REVIEW.md. Design rule: one stable skeleton. Screens 1, 6 and 7 are the same layout in three states (results, first run, scanning); no element changes position between them. Same 460 × 640 window. Changes: one scan row, Export as the single primary action, tabbed Settings with output formats first, a 4 / 8 / 12 / 16 spacing scale, and clearly visible active states (tabs, chips, segments, selected rows, format cards). Use the toggle to check dark mode.
